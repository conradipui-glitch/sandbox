# Визуальная библия — «Переиграть историю»

## Художественная формула

**Живой театр бумажной истории:** политический плакат + архивная газетная печать + театральная декорация + сдержанная живописная фигура.

Визуал не украшает интерфейс, а сообщает состояние мира. Свет, плотность толпы, сохранность карты, количество документов и поведение персонажей меняются вместе с политическими показателями.

## Палитра

| Роль | Цвет | Применение |
|---|---|---|
| Угольный фон | `#12110F` | основной фон и глубокие тени |
| Архивная бумага | `#E9E0CC` | документы, заголовки, свет |
| Кирпично-красный | `#C94C36` | решения, опасность, печати |
| Приглушённое золото | `#B3975A` | власть, статус, редкий акцент |
| Пыльно-серый | `#938C7D` | вторичный текст и архивность |

## Персонажи

- полный силуэт, чистый alpha-край, прозрачный фон;
- руки отделены от корпуса, ноги визуально читаются;
- историческая достоверность важнее театрального костюма;
- выразительность без карикатуры и фотореализма;
- красный используется только в сюжетно значимом предмете;
- базовый размер вертикального ассета — `1024×1536`;
- для Web после утверждения создаётся оптимизированная WebP-версия.

### Анимационная грамматика

| Событие | Движение |
|---|---|
| Вход персонажа | 500–900 мс, сдвиг 40–80 px и появление |
| Ожидание | дыхание 4–7 секунд, масштаб не более 0,8% |
| Тревога | слабая нерегулярная вибрация, уменьшение насыщенности |
| Поддержка | небольшой шаг к игроку, более тёплый свет |
| Противодействие | отступление в тень или поворот от центра |
| Важное решение | удар печати, дрожание бумаги, короткая красная вспышка |

Движение не должно превращаться в постоянное мельтешение. В одной сцене одновременно активны не более двух заметных анимаций.

## Сцены

Каждая сцена состоит минимум из четырёх слоёв:

1. дальний архитектурный фон;
2. средний смысловой объект — карта, окно, трибуна или печатный станок;
3. персонаж или группа;
4. передний план — стол, документы, дым, толпа или снег.

CSS отвечает за параллакс, освещение и атмосферу. Растровая генерация используется для персонажей и сложных живописных планов. Точный UI, карты причин и надписи остаются HTML/SVG.

## Эталонный промпт персонажа

```text
Use case: historical-scene
Asset type: layered 2D game character cutout
Subject: period-accurate full-body political character, March 1917
Style: editorial historical illustration, paper theatre, gouache and restrained linocut texture
Composition: isolated full-body silhouette; arms separated from torso; generous transparent margin
Palette: paper cream, charcoal, muted gold, one controlled brick-red accent #C94C36
Constraints: actual transparent alpha; no text; no frame; no floor; no cast shadow; no modern details
Avoid: photorealism, glossy 3D, anime, caricature, cropped shoes, duplicated limbs
```

## Производственные правила

- исходный PNG сохраняется как мастер;
- WebP/AVIF создаются только после утверждения мастер-ассета;
- имя файла описывает роль, эпоху и вариант;
- обязательны мобильная проверка и `prefers-reduced-motion`;
- декоративный текст внутри сгенерированной картинки не используется для критической информации;
- каждый новый ассет проходит проверку силуэта на ширине 160 px.
- привлекательность персонажа не заменяет субъектность: внешность, профессия, власть и уязвимость проектируются вместе;
- техника рисуется отдельным прозрачным ассетом и появляется лишь при наличии сюжетной функции.
