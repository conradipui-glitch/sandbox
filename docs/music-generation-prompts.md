# Музыка для «Переиграть историю»

Пакет подготовлен так, чтобы файлы можно было сразу подключить к экранам и игровым состояниям. Сохраняйте **точные имена файлов** из списка ниже.

## Общие параметры генерации

- Инструментал: без слов, речи, вокала и хора.
- Формат: предпочтительно MP3, 320 kbps. WAV тоже подойдёт — имя оставьте тем же, заменив только расширение.
- Для длинных тем нужен мягкий бесшовный цикл: без громкого начала и окончательной каденции.
- Музыка вдохновлена эпохой, но не цитирует реальные гимны, марши и известные мелодии.
- Общий звуковой почерк: подготовленное пианино, низкие струнные, бас-кларнет, гармониум, сухая перкуссия, фактура граммофона, телеграфа и железной дороги.
- Если генератор предлагает варианты, выбирайте сдержанный кинематографичный вариант без «трейлерной» помпезности.

## Как прислать файлы

Можно прислать MP3 или WAV одним архивом либо по отдельности. Главное — сохранить указанные базовые имена. Если генератор выдаёт несколько вариантов одной темы, добавьте суффиксы `-v1`, `-v2`, например `music-03-campaign-cabinet-v2.mp3`; после прослушивания выбранный вариант получит основное имя.
