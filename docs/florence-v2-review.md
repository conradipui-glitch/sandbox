# Флоренция: редакция 2 — авторский плейтест

Исторический отчёт о словарном прототипе. Он не подтверждает работу свободного текста через ИИ и литературное качество живого прохождения. Текущая архитектура и проверка описаны в [florence-ai-playtest.md](florence-ai-playtest.md); живой маршрут больше не использует этот резолвер.

## Что изменилось

Сцена больше не выбирает общий «тон» по имени персонажа. Действие изменяет явные факты: показанный картон, помощь Джулиано, договор, аванс, проверенная краска, свидетельство, публичный ответ. Предложение договора отдельно от согласия. Полученный аванс отдельно от предложенного. Отказ не требует разрешения заказчика.

В каждой сцене три предложения с разными последствиями. Их формулировки учитывают состояние: например, без полученного аванса предлагается отозвать предложение, а не возвращать несуществующие деньги. Проба краски меняет публичный ход. Финальный акт учитывает прекращённую сделку.

Карточка читается по порядку: последствие → разговор и цена → следующая ситуация → новые действия. Эпилог выводится абзацами, после него можно раскрыть полный список совершённых действий и их цены. Вопрос для размышления связан с конкретным прохождением.

## Проверка механики

Автоматические проверки покрывают все 729 сочетаний подготовленных решений (3 в каждой из 6 сцен), завершение и отсутствие пустых финалов. Это проверка переходов, не оценка литературного качества 729 историй.

Отдельные проверки: три контрастных пути; просьба без выдуманного согласия; отказ; возврат реально полученного аванса; неизвестная и отрицаемая команда; составной ход целиком; повтор без повторной оплаты; сохранение/восстановление; невозможное действие в финальной сцене; старое сохранение без фактов.

Уточнения и невозможные действия не расходуют сцену, не меняют показатели и не засчитываются сервером как осмысленные действия в продуктовой аналитике.

## Три маршрута для чтения

1. Переговоры: картон → накладная → встречный договор → проба → публичный разговор → фрагмент. Ожидается «Незавершённое принято»: право на имя получено, работа остаётся неполной.
2. Деньги для мастерской: лекарь → ученики → аванс без имени → свидетельство → открытый расчёт → фрагмент. Ожидается «Чужое имя над вашей работой»: помощь человеку и оплата имеют цену в авторстве.
3. Отказ: закрытая дверь → отказ от аванса → ответственность мастера → свидетельство → остановка смены → имя. Ожидается «Имя без заказчика»: право поставить имя не означает обязанность заказчика принять работу.

После прочтения: какая реплика действительно ответила на ваш ход; где возникло желание сделать следующий; какое последствие оказалось неожиданным, но понятным; где автор гипотезы перестал узнавать замысел?

## Границы этой редакции

Свободный ввод использует детерминированный разбор ряда перефразировок. Это ещё не универсальное понимание текста: неизвестные формулировки просят уточнить, а не исполняют по догадке. Несколько поддержанных действий можно разделять точкой с запятой. Новые действия за пределами авторского набора пока не создают новых механик. LLM в этой редакции не включена.

Экономика остаётся моделью нескольких событий и показателей, не полноценной бухгалтерией. Развязка сохраняет денежные обязательства, но не обещает точной симуляции цен эпохи.

Поставка краски даёт интригу с ограниченным знанием: проба доказывает дефект, свидетель подтверждает вскрытую печать; это не доказательство личности виновного. Эпилог не выдумывает раскрытого преступления.

Старые сохранения после первой сцены требуют нового старта: в них не записаны факты новой механики. Они не удаляются, прошлые решения не реконструируются по ключевым словам.

## Отдельное предложение об объединении гипотез

Общее ядро для разных историй может хранить действие, проверенные изменения мира, реакцию сторон и цену. Авторская гипотеза задаёт конфликты причинности, интересов других и права на отказ. Литературный слой превращает изменения в сцену. Добровольная рефлексия возвращает игроку конкретные решения и вопрос о его собственном замысле.

Это предложение для команды, не перенос правил Флоренции в 1917 или Академию. Следующий этап — авторский плейтест и исправления по его результату. Сравнение baseline/principles и исследование удержания ещё не проведены.
